# pqcrypto-lab Roadmap

## Current Status

Completed:

* Modular Arithmetic
* Extended Euclidean Algorithm
* Miller-Rabin Primality Test
* RSA
* Polynomial Arithmetic
* Number Theoretic Transform (NTT)
* Polynomial Ring Arithmetic
* Simplified Kyber Demonstration

Documentation:

* Number Theory Notes
* PQC Overview
* Kyber Study Notes
* Dilithium Study Notes

---

## Short-Term Goals

* Expand unit testing
* Improve documentation
* Add benchmark scripts
* Improve project structure

---

## Mid-Term Goals

* Implement educational lattice-based cryptography examples
* Study CRYSTALS-Kyber reference implementation
* Study CRYSTALS-Dilithium reference implementation
* Add performance measurements

---

## Long-Term Goals

* Develop a complete educational PQC toolkit
* Build visualization tools for lattice cryptography
* Create interactive learning resources
* Explore advanced post-quantum algorithms

---

## Vision

The goal of pqcrypto-lab is to become an open-source educational resource that helps students and developers understand modern cryptography and post-quantum cryptography through practical implementations and documentation.
